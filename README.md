# Agri Equipment Rental System  
### Shete Krushi Seva

---

## Project Overview
Agri Equipment Rental System is a full-stack web application designed to help farmers rent agricultural equipment easily.  
Owners can manage equipment, pricing, and availability, while farmers can browse and book equipment online.

---

## Objectives
- Digitize agricultural equipment rental process
- Reduce manual dependency for farmers
- Provide easy access to equipment on rent
- Enable owners to manage equipment efficiently

---

## Tech Stack

### Frontend
- React (Vite)
- JavaScript
- HTML
- CSS

### Backend
- Spring Boot
- Java
- REST APIs

### Database
- MySQL

---

## User Roles

### ADMIN (Owner)
- Add new equipment
- Update equipment price & availability
- Delete equipment
- View dashboard summary

### USER (Farmer)
- View available equipment
- Book equipment
- View rental history

---

## Key Features
- Role-based authentication
- Equipment booking system
- Owner dashboard
- Secure backend APIs
- Clean and responsive UI

---
